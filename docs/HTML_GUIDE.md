# HTML5 Quick Guide

## A valid document
```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Descriptive page title</title>
</head>
<body><main><h1>Page heading</h1><p>Page content.</p></main></body>
</html>
```

Use headings for hierarchy, paragraphs for prose, lists for grouped items, links for navigation and buttons for actions. Use tables for tabular data, not layout.

Choose semantic elements such as `header`, `nav`, `main`, `article`, `section`, `aside` and `footer` when their meanings match the content. A page normally has one primary main landmark.

Give informative images concise alt text; use empty alt for decorative images. Associate labels with form controls. Native browser validation is not server-side validation.

Indent consistently, quote attributes, use unique IDs and avoid obsolete presentational elements. Validate markup and test with keyboard and assistive technology.
