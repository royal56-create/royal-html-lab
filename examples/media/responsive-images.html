Responsive images

Use srcset and sizes to let the browser choose an appropriate image candidate. Use picture when art direction or format selection is needed.

Image authoring checklist

  • Write useful alternative text for informative images.
  • Use empty alt text for decorative images.
  • Set intrinsic width and height to reduce layout shifts.
  • Use modern formats and appropriately sized files.
  • Do not lazy-load the page's main hero image by default.
