# Security and Responsible Use

This repository contains educational examples and demonstration code, not a production security guarantee.

- Review code and commands before running them.
- Use examples only on files, devices, and systems you own or are explicitly authorized to use.
- Do not enter real passwords, personal information, or confidential data into demonstrations.
- Keep independent backups and test changes in a disposable environment.
- Report suspected project vulnerabilities privately to the repository maintainer.
