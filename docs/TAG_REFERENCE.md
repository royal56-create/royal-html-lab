# HTML Element Reference

| Purpose | Common elements |
|---|---|
| Document | `html`, `head`, `body`, `title`, `meta`, `link` |
| Sectioning | `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` |
| Text | `h1`–`h6`, `p`, `strong`, `em`, `blockquote`, `code` |
| Lists | `ul`, `ol`, `li`, `dl`, `dt`, `dd` |
| Media | `a`, `img`, `picture`, `audio`, `video`, `source`, `figure`, `figcaption` |
| Tables | `table`, `caption`, `thead`, `tbody`, `tr`, `th`, `td` |
| Forms | `form`, `label`, `input`, `select`, `option`, `textarea`, `button`, `fieldset`, `legend` |
| Native interactive | `details`, `summary`, `dialog`, `progress`, `meter` |

Useful attributes: `id` identifies one element; `class` groups elements; `href` gives a link destination; `src` gives a resource location; `alt` supplies an image text alternative; `lang` identifies language; `required`, `min`, `max` and `pattern` define native constraints.

Avoid obsolete elements such as `font`, `center` and `marquee`.
