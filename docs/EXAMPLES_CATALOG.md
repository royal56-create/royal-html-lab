# Additional HTML Examples

This catalog lists extra standalone examples added to the lab. Open each file in a browser or inspect its source.

| Example | What it demonstrates |
|---|---|
| [Native dialog](../examples/advanced-elements/dialog.html) | The `dialog` element, modal display and focus return |
| [Form validation](../examples/forms/form-validation.html) | Required fields, input types, length and range constraints |
| [Responsive images](../examples/media/responsive-images.html) | `picture`, `source`, alternative text and image sizing |
| [Semantic article](../examples/semantic-html/article-layout.html) | Article structure, landmarks, headings and publication time |
| [Structured data](../examples/seo/structured-data.html) | An illustrative JSON-LD block |
| [Accessible table](../examples/tables/accessible-table.html) | Caption, column headers, row headers and scope |

## Reusable starter

[Blank HTML5 starter template](../templates/blank-starter.html) provides a semantic page shell that can be copied and adapted.

## Important notes

- These examples are educational starting points, not production guarantees.
- The dialog example uses a small amount of JavaScript to call the browser's native dialog API.
- The form examples validate in the browser only; they do not securely process or store submissions.
- Replace all placeholder content and sample structured data before publishing a real website.
