Untrusted text

Production checklist

  • Escape or safely encode untrusted data for its output context.
  • Do not insert untrusted strings with innerHTML; use textContent for plain text.
  • Validate data on the server; browser validation is not a security boundary.
  • Configure HTTPS, Content Security Policy and appropriate security headers on the server.
  • Sandbox third-party frames and grant only required permissions.
