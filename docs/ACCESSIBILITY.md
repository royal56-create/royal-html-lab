# HTML Accessibility Checklist

- [ ] Set the document language correctly.
- [ ] Provide a descriptive page title.
- [ ] Include a skip link on longer pages.
- [ ] Use landmarks and a logical heading hierarchy.
- [ ] Give informative images useful alt text; use empty alt for decorative images.
- [ ] Associate every form control with a label.
- [ ] Use meaningful link text.
- [ ] Use buttons for actions and links for navigation.
- [ ] Ensure native controls work with a keyboard.
- [ ] Do not communicate meaning by colour alone.
- [ ] Test zoom, reflow and visible focus.
- [ ] Test with assistive technology when practical.

Prefer native HTML before adding ARIA. Incorrect ARIA can make an interface less understandable.
