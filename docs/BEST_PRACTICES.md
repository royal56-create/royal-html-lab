# HTML Best Practices

1. Start each document with `<!doctype html>`.
2. Set the document language and character encoding.
3. Give every page a unique, descriptive title.
4. Use semantic elements based on meaning.
5. Keep heading levels logical and IDs unique.
6. Quote attribute values and use lowercase names.
7. Use labels and native form constraints.
8. Add appropriate alternative text to images.
9. Use tables only for data.
10. Avoid deprecated elements and unnecessary ARIA.
11. Keep file paths and names consistent.
12. Validate markup and test with real browsers.
13. Never treat client-side validation as security.
14. Do not collect or transmit user data without a secure, clearly explained purpose.
