# HTML SEO Foundations

Good HTML helps people and search engines understand a page, but metadata alone cannot guarantee rankings.

- Write a unique, accurate `title` for each page.
- Add a concise, page-specific meta description.
- Use headings that describe the content hierarchy.
- Make important content available as crawlable text.
- Use descriptive link text and useful image alternatives.
- Use a canonical URL only when you know the preferred public URL.
- Open Graph fields can provide social preview title, description and URL.
- A sitemap lists canonical URLs for discovery.
- robots.txt gives crawler instructions; it is not a security boundary.

Replace example URLs and metadata before publishing a real site.
