# Contributing

Thanks for helping improve Royal Web Structure Lab.

- Keep examples focused on HTML5 and document structure.
- Prefer native browser features and local assets.
- Do not add API keys, credentials, tracking scripts or unnecessary external dependencies.
- Do not include copyrighted media unless you have permission.
- Explain when an example is illustrative rather than production-ready.

## Pull request checklist
- [ ] Descriptive lowercase file names.
- [ ] Doctype, language, charset and viewport where appropriate.
- [ ] Valid local links and asset paths.
- [ ] Form controls have labels.
- [ ] Images have appropriate alt text.
- [ ] Run `python scripts/check_html.py`.
- [ ] Update documentation when needed.

Keep pull requests focused and describe what changed and how you tested it.
