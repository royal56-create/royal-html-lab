Why semantic HTML matters

Published 21 November 2026

Semantic elements describe the purpose of content. They help browsers, assistive technologies and developers understand a page's structure.

Clear structure

Use headings in a logical order and choose elements according to their meaning, not their default appearance.

Meaningful elements

Use nav for navigation, main for the page's main content, and aside for complementary content.
